## 과제 개요

```c
int ft_printf(const char *format, ...);
```

포맷 문자열을 파싱해 각 변환 지정자에 맞는 가변 인자를 출력합니다.  
실제 출력된 문자 수를 반환합니다 (`printf`와 동일한 반환값 규칙).

허용 함수: `malloc`, `free`, `write`, `va_start`, `va_arg`, `va_end`, `va_copy`

---

## 핵심 개념

### 가변 인자 함수 (Variadic Function)

`printf`처럼 인자 개수가 고정되지 않은 함수입니다.  
`<stdarg.h>`의 매크로를 사용해 인자를 하나씩 꺼내 처리합니다.

```c
va_list args;
va_start(args, format);   // 마지막 고정 인자(format) 다음부터 시작
va_arg(args, int);        // 다음 인자를 int로 꺼냄
va_end(args);             // 정리
```

**동작 원리**  
함수가 호출될 때 인자들은 스택에 순서대로 쌓입니다.  
`va_start`는 마지막 고정 인자의 주소를 기준으로 포인터를 초기화하고,  
`va_arg`는 타입 크기만큼 포인터를 이동하며 다음 인자를 꺼냅니다.  
따라서 `va_arg`에 넘기는 타입이 실제 인자 타입과 다르면 잘못된 값을 읽게 됩니다.

### 포맷 문자열

`printf`의 포맷 문자열은 `%`를 기준으로 일반 문자와 변환 지정자로 나뉩니다.

```
"Hello %s, you are %d years old"
        ^^           ^^
        변환 지정자   변환 지정자
```

`%` 를 만나면 다음 문자를 읽어 어떤 지정자인지 판단하고, 가변 인자 목록에서 대응하는 인자를 꺼내 변환합니다.

## 구현 흐름

```
ft_printf(format, ...)
    │
    ├── 포맷 문자열 순회
    │     │
    │     ├── 일반 문자 → write()로 출력, count++
    │     │
    │     └── '%' 발견
    │           │
    │           └── 다음 문자 확인
    │                 ├── 'c' → va_arg(char) → 출력
    │                 ├── 's' → va_arg(char*) → 출력
    │                 ├── 'd'/'i' → va_arg(int) → 정수 변환 → 출력
    │                 ├── 'u' → va_arg(unsigned int) → 변환 → 출력
    │                 ├── 'x'/'X' → va_arg(unsigned int) → 16진수 변환 → 출력
    │                 ├── 'p' → va_arg(void*) → 주소 → 16진수 변환 → 출력
    │                 └── '%' → '%' 출력
    │
    └── 출력된 총 문자 수 반환
```

## 지원 변환 지정자

| 지정자 | 대응 타입 | 출력 형식 |
|---|---|---|
| `%c` | `int` (char) | 단일 문자 |
| `%s` | `char *` | 문자열 (`NULL`이면 `"(null)"`) |
| `%p` | `void *` | 포인터 주소 (`0x` + 16진수) |
| `%d` / `%i` | `int` | 부호 있는 10진 정수 |
| `%u` | `unsigned int` | 부호 없는 10진 정수 |
| `%x` | `unsigned int` | 16진수 소문자 |
| `%X` | `unsigned int` | 16진수 대문자 |
| `%%` | — | `%` 문자 출력 |

---

## 각 지정자 구현 방식

### %c

`va_arg(args, int)`로 꺼냅니다. `char`가 아닌 `int`인 이유는 C에서 가변 인자 전달 시 `char`가 `int`로 자동 승격(integer promotion)되기 때문입니다.

### %s

`NULL` 포인터 처리가 필요합니다. `printf`는 `NULL`이 들어오면 `(null)`을 출력합니다.

### %p

포인터를 `unsigned long`으로 캐스팅해 16진수로 변환합니다.  
`0x` 접두사를 앞에 붙이고 `NULL` 포인터는 `(nil)`로 출력합니다.

### %d / %i

음수 처리가 핵심입니다. `INT_MIN`(`-2147483648`)은 절댓값을 취하면 오버플로우가 발생합니다.  
`unsigned int`로 캐스팅해 처리하거나 별도로 예외 처리합니다.

### %u

`unsigned int`로 꺼내므로 음수가 없습니다. 10진수 변환만 구현합니다.

### %x / %X

재귀 또는 반복으로 16진수 변환합니다.  
`"0123456789abcdef"` 또는 `"0123456789ABCDEF"` 배열을 인덱스로 참조합니다.

```c
// 재귀 방식
void ft_putnbr_hex(unsigned int n, const char *base)
{
    if (n >= 16)
        ft_putnbr_hex(n / 16, base);
    ft_putchar(base[n % 16]);
}
```

### %%

`%`를 만났을 때 다음 문자도 `%`이면 `%` 하나를 출력하고 카운트를 1만 증가시킵니다.

## 깨달은 점

**가변 인자는 타입 안정성이 없다**  
`va_arg`에 잘못된 타입을 넘기면 잘못된 메모리를 읽습니다. `printf`가 포맷 지정자와 인자 타입이 일치해야 하는 이유가 여기에 있습니다. 컴파일러 경고(`-Wformat`)가 이를 잡아주지만, 런타임에서는 직접 확인할 방법이 없습니다.

**`char`가 `int`로 전달되는 이유**  
C의 암묵적 타입 승격(integer promotion) 규칙에 따라 `char`, `short` 등은 가변 인자로 전달될 때 자동으로 `int`로 승격됩니다. `va_arg`를 `char`로 호출하면 잘못된 값을 읽게 됩니다.

**`INT_MIN` 처리는 항상 특별하다**  
`-2147483648`의 절댓값은 `int` 범위를 벗어납니다. 정수를 문자열로 변환하는 함수를 만들 때마다 이 케이스를 반드시 확인해야 합니다.

**출력 함수를 직접 만드는 것의 의미**  
`printf` 하나로 당연하게 출력하던 것들이 내부적으로 포맷 파싱, 타입 변환, 재귀적 진수 변환 등 여러 단계로 이루어진다는 걸 직접 구현하면서 알게 됐습니다.
